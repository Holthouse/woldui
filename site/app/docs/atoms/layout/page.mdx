Gaps come from one named scale: `none`, `xs` (4px), `sm` (8px), `md` (16px), `lg` (24px) and `xl` (32px). There is no arbitrary value, so spacing stays on the grid. Every primitive still takes `className` for anything else.

## Stack

Vertical flow, and the default container for anything that reads top to bottom. `gap` defaults to `md`. `align` sets the cross axis and defaults to `stretch`.

<Example name="atoms-layout/stack">
	<StackExample />
</Example>

## Inline

Horizontal flow. It wraps by default, because a row of text-bearing items overflows on a phone; pass `wrap={false}` to stop it. `justify` spreads the items and `align` defaults to `center`.

<Example name="atoms-layout/inline">
	<InlineExample />
</Example>

## Grid

A grid that reflows without breakpoints: `min` is the narrowest a column may get (default `16rem`), and the grid fits as many columns as it can. It deliberately takes no column count, because a fixed count is what forces breakpoint juggling later.

<Example name="atoms-layout/grid">
	<GridExample />
</Example>

`Box` is a plain `<div>` that takes a `className`, for when you need a styling hook and nothing more.

## Accessibility

- Every primitive renders a `<div>` and adds no semantics. Use `<ul>`, `<nav>` or `<section>` inside, or pass a `role`, when the structure means something.
- Visual order follows source order: none of them reorder their children, so the tab order and the reading order match what is on screen.
- `Inline` wraps rather than overflowing, which keeps content reachable at 400% zoom without scrolling sideways.
