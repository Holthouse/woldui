Pass the lucide component itself to `icon`, not an element. `size` runs `xs` (12px), `sm` (16px, the default), `md` (20px) and `lg` (24px), and the stroke is always 1.75.

## Decorative or meaningful

`label` is required. An icon beside a visible label is decorative: pass `label={null}` and it is hidden from assistive tech. An icon that carries meaning on its own gets a string, which becomes its accessible name.

</Example>

<Callout>
	`label` is required on purpose. There is no third case, and getting it wrong is silent: a
	meaningful icon with no name, or a decorative one read out twice. Making you type `null` turns
	that into a decision.
</Callout>

## Accessibility

- `label={null}` sets `aria-hidden`, so a screen reader skips the icon.
- A string label sets `role="img"` and `aria-label`, so the icon is announced by that name.
- The icon is never focusable. An icon-only button still needs an `aria-label` on the button; give the icon inside it `label={null}`.
- A coloured icon that shows status should use a `-text` token (`text-success-text`), which keeps AA contrast where the raw tone does not.
