A horizontal separator fills the width. `orientation="vertical"` stretches to the height of its row, so give the row a height.

## Accessibility

- It is decorative by default and hidden from assistive tech, because most rules only separate visually.
- When the break is meaningful, as between two groups of menu items, pass `decorative={false}` and it becomes a `separator` role with `aria-orientation`.
