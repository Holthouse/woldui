## Usage

<Example name="input-group/usage">

The group owns the fill, border and focus style, so use `InputGroupInput` inside it, not a plain `Input`. Clicking an addon focuses the input.

## Text and buttons

`align` places an addon: `inline-start` (the default) or `inline-end`. `InputGroupText` holds a prefix or suffix, and `InputGroupButton` is a compact button sized to sit inside the field.

<Example name="input-group/text-and-button">
	<TextAndButton />
</Example>

## With a textarea

`block-start` and `block-end` put an addon above or below the control, and the group grows to fit. This suits a composer with a toolbar.

<Example name="input-group/textarea">
	<Textarea />
</Example>

## Accessibility

- The input still needs a label. A search icon is not one: give `InputGroupInput` an `aria-label` or a `Label`.
- Icons in an addon are decorative; mark them `aria-hidden`. An icon-only `InputGroupButton` needs an `aria-label`.
- `aria-invalid` on the input turns the whole group's border to the danger colour.
- `InputGroupButton` defaults to `type="button"`, so it never submits the surrounding form by accident.
