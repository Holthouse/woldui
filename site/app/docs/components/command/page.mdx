## Usage

<Example name="command/usage">
	<Usage />
</Example>

Typing filters and ranks the items. `CommandEmpty` shows when nothing matches, and groups with no matches hide themselves. `CommandShortcut` only displays a shortcut: it does not bind the key.

## Command palette

`CommandDialog` puts the same parts in a [Dialog](/docs/components/dialog), positioned in the top third of the screen. The usual way to open it is Ctrl+K (Cmd+K on a Mac), which you bind yourself, as here. Keep a visible button as well, because a shortcut alone cannot be discovered.

<Example name="command/dialog">
	<CommandDialogExample />
</Example>

## Accessibility

- The input is a combobox that controls the list. Arrow keys move through the items, Enter runs the selected one, and the active item is announced as you move.
- The selection is virtual: focus stays in the input, so the user can keep typing at any point.
- `CommandDialog` gives the dialog a screen-reader-only title and description. Change them with its `title` and `description` props to describe your palette.
- Icons in items are decorative: give them `aria-hidden` and let the item's text be its name.
