## Usage

<Example name="questionnaire/usage" align="start" tall>
	<Usage />
</Example>

`Questionnaire` is a `<form>`. Each `QuestionnaireItem` is one step, named by `name`, and only the current step shows. `QuestionnaireChoice`s are radio buttons, or checkboxes when the item is `multiple`. `QuestionnaireProgress` counts the steps. In `QuestionnaireActions`, Next hides on the last step and Submit takes its place. Enter presses whichever of the two is showing.

## Text answers and skipping

`QuestionnaireInput` takes a typed answer. A `required` item blocks Next until it is answered, and `QuestionnaireError` shows why. `QuestionnaireSkip` moves past an optional item, and `QuestionnaireChoiceDescription` adds a second line to a choice.

## Accessibility

- Each item is a `<fieldset>` and its title a `<legend>`, so the question names the group of choices.
- Choices are native radio and checkbox inputs under the visible card, so Tab, the arrow keys and Space behave as usual.
- Moving between items sends focus to the new question. Hidden buttons get the `hidden` and `inert` attributes, so they leave the tab order.
- A text input inside an item needs a name of its own: an `aria-label` or a visible label.
