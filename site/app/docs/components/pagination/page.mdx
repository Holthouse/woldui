## Usage

<Example name="pagination/usage">

Each link is a [Button](/docs/components/button) rendered onto an `<a>`. `isActive` gives the current page a bordered button; the rest are ghost buttons. On narrow screens Previous and Next shrink to their chevrons. Pass `text` to change their labels.

## Accessibility

- `Pagination` is a `<nav>` labelled "pagination".
- `isActive` sets `aria-current="page"` on the current page's link.
- Previous and Next have their own `aria-label`s ("Go to previous page", "Go to next page"), so they stay named when the visible text is hidden.
- `PaginationEllipsis` is `aria-hidden`. It is a gap in the list, not a control.
- With a router, handle navigation in `onClick` or wrap the links, and keep a real `href` so each page has a URL.
