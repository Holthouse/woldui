Each part is the matching native element (`<table>`, `<thead>`, `<th>` and so on), lightly styled. `Table` wraps the `<table>` in a container that scrolls sideways when the columns don't fit. Right-align numeric columns and set them `tabular-nums` so the digits line up.

## Selectable rows

A row with `data-state="selected"` is highlighted. The selection itself is yours to hold in state; here a checkbox per row and an indeterminate one in the header drive it. Cells can hold any component, such as an avatar or a badge.

## Accessibility

- It renders a real `<table>`, so screen readers announce row and column counts and read each cell with its column header.
- `TableCaption` names the table. Include one, or give the table an `aria-label` or `aria-labelledby`.
- `TableHead` renders `<th>`. Add `scope="col"` or `scope="row"` in tables where a header's direction is ambiguous.
- Every checkbox needs its own `aria-label` naming the row it selects, since it has no visible label.
- The selected highlight is visual only; the checked state of the checkbox is what assistive tech reports.
