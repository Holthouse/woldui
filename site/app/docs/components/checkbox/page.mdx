## Accessibility

- It renders a `<button role="checkbox">` with `aria-checked`, so Space toggles it and it joins the tab order.
- Give it a `Label` with a matching `htmlFor`. Clicking the label toggles the box, and the hit area extends past the 16px box itself.
- Link help text with `aria-describedby`, and mark an invalid box with `aria-invalid`.
- Inside a `<form>`, a hidden native checkbox carries `name` and `value`, so it submits like a native one.
