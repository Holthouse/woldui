## Accessibility

- `Breadcrumb` is a `<nav>` labelled "breadcrumb", and the trail is an ordered list, so screen readers announce it as a landmark with a count of levels.
- `BreadcrumbPage` carries `aria-current="page"`.
- Separators and the ellipsis are `aria-hidden`, so they are not read between every level.
- With a router, pass `asChild` to `BreadcrumbLink` and put your router's link inside it.
