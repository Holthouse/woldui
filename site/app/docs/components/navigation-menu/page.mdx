## Usage

<Example name="navigation-menu/usage" align="start" tall>
	<Usage />
</Example>

A `NavigationMenuTrigger` opens its `NavigationMenuContent`. A plain link sits in the same row: give it `navigationMenuTriggerStyle()` so it lines up with the triggers.

By default the panels render into one shared viewport under the list, which resizes and slides as you move between items. Pass `viewport={false}` to have each panel open directly below its own trigger instead.

## Accessibility

- It renders a `<nav>` with a list of items. Give it an `aria-label` if the page has more than one navigation landmark.
- Tab moves between the top-level items, Enter or Space opens a panel, and Arrow Down moves into it. Escape closes it and returns focus to the trigger.
- Panels also open on hover, but they never depend on it: every link is reachable with the keyboard alone.
- Set `active` on the `NavigationMenuLink` for the current page, which adds `aria-current="page"`.
