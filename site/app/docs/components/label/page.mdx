## Accessibility

- It renders a native `<label>`. Set `htmlFor` to the control's `id` so the label becomes the control's accessible name.
- Clicking the label focuses an input or toggles a checkbox or switch, which gives small controls a larger target.
- A label placed after a disabled control (as its `peer`) dims to match it.
