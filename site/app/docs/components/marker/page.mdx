## Variants

`separator` draws a rule on each side of centred text, for date dividers. `border` adds a rule underneath.

## Accessibility

- `MarkerIcon` is `aria-hidden`, so the text has to carry the meaning on its own.
- The rules drawn by `separator` and `border` are CSS, not `<hr>` elements, so they aren't announced. Only the text is read.
- Markers use `muted-foreground`, which passes AA on the page background. Don't place them on a `muted` fill.
