## Variants and sizes

`variant` is `default` or `outline`, and `size` is `sm`, `default` or `lg`. A toggle can hold text as well as an icon.

<Example name="toggle/variants">

</Example>

For a row of toggles that work together, use [Toggle Group](/docs/components/toggle-group/).

## Accessibility

- It renders a `<button>` with `aria-pressed`, so Space and Enter toggle it and a screen reader announces "pressed" or "not pressed".
- An icon-only toggle needs an `aria-label`. Keep it constant ("Bold"); the pressed state is announced separately.
- Use `pressed` and `onPressedChange` to control it, or `defaultPressed` to set where it starts.
