## Accessibility

- The group renders with `role="group"`. Give it an `aria-label` so a screen reader announces what the buttons have in common.
- Each segment stays its own tab stop; the group adds no arrow-key navigation. For a set of options where one is chosen, use [Toggle Group](/docs/components/toggle-group/) instead.
- The focused segment is lifted above its neighbours, so its focus ring is not clipped by the next button.
