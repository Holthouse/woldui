It uses `field-sizing: content`, so it grows as the text does, starting from `rows` (or a 64px minimum). Cap it with a `max-h-*` class if it should scroll instead. It cannot be resized by dragging.

## Accessibility

- It renders a native `<textarea>`, so every browser behaviour, from spell-check to form submission, is unchanged.
- Label it with a `Label` and `htmlFor`, or with the [Field atom](/docs/atoms/field/), which also wires a description, a character counter and an error.
- Mark an invalid field with `aria-invalid` and point `aria-describedby` at the message.
