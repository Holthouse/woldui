## Setup

WoldUI exports one thing here: `Toaster`, the stack that toasts appear in. Mount it once, near the root of the app, so every page shares it. It follows the theme from `next-themes` and takes WoldUI's popover colours and radius.

```tsx
import { Toaster } from '@woldui/react/components/ui/sonner';

export default function RootLayout({ children }: { children: React.ReactNode }) {
	return (
		<html lang="en">
			<body>
				{children}
				<Toaster />
			</body>
		</html>
	);
}
```

Then call `toast()` from anywhere. It comes from the `sonner` package itself, not from WoldUI, and needs no provider or hook.

## Types

`toast.success`, `toast.info`, `toast.warning` and `toast.error` each get their own icon, and are tinted with that tone: its surface, its border and text at the step that stays legible on the tint in both themes. Pass `richColors={false}` to `Toaster` if you would rather every toast used the neutral popover surface.

## Accessibility

- The toaster is a labelled region, and new toasts are announced through a polite live region, so they do not interrupt what a screen reader is saying.
- Alt+T moves focus to the toast stack, so keyboard users can reach an action button before the toast times out.
- Hovering or focusing the stack pauses the timers.
- A toast disappears on its own. Never put the only route to something important in one: an undo is fine, a required decision is not.
- For errors the user must act on, prefer an inline [Alert](/docs/components/alert) that stays on the page.
