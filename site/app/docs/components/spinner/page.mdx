## Accessibility

- On its own it has `role="status"` and the name "Loading". Pass a more specific `aria-label`, such as "Loading comments", when you can.
- Where nearby text already says it is loading, add `aria-hidden` so it is not announced twice.
- It spins with `animate-spin`. Add `motion-reduce:animate-none` if your app stops all continuous motion under reduced motion.
