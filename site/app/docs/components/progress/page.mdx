## Accessibility

- It renders `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and `aria-valuenow` set from `value` and `max`.
- Give every bar a name with `aria-label` or `aria-labelledby`, so it is clear what is progressing.
- Leave `value` out (or pass `null`) for an indeterminate task. The bar stays empty, so pair it with text or a [Spinner](/docs/components/spinner).
