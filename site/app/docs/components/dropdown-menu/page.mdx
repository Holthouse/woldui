## Usage

<Example name="dropdown-menu/usage">
	<Usage />
</Example>

The menu is as wide as its trigger by default; set a width with `className` when the items need more room. `variant="destructive"` colours an item red. `DropdownMenuShortcut` only displays a shortcut: it does not bind the key.

## Checkbox and radio items

`DropdownMenuCheckboxItem` toggles a setting on its own. `DropdownMenuRadioItem`s inside a `DropdownMenuRadioGroup` pick one value from several. Control them with `checked` / `onCheckedChange` and `value` / `onValueChange`. Like any item, choosing one closes the menu; call `event.preventDefault()` in `onSelect` to keep it open.

<Example name="dropdown-menu/checkbox-radio">
	<CheckboxRadio />
</Example>

## Accessibility

- Enter, Space or Down on the trigger opens the menu and focuses the first item. Arrow keys move, and typing a letter jumps to the item that starts with it.
- Right opens a submenu and Left closes it. Escape closes the menu and returns focus to the trigger.
- Checkbox and radio items carry `menuitemcheckbox` and `menuitemradio` roles, so their checked state is announced.
- An icon-only trigger needs an `aria-label` that says what the menu is for, such as "Project actions".
