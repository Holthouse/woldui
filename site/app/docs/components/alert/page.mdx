## Live region role

Every alert renders with `role="alert"`, which interrupts a screen reader. For news that can wait, such as a saved confirmation, pass `role="status"` to have it announced politely.

## Accessibility

- `Alert` has `role="alert"`, an assertive live region: content that appears after the page loads is read out straight away. Keep that for messages that need attention now, and pass `role="status"` for everything else.
- An alert already on the page when it loads is not announced, so do not rely on it for news the user must hear.
- `AlertIcon` is `aria-hidden`. The title carries the meaning, and the glyph repeats it for sighted users.
- The tone is never the only signal: the title's wording and the glyph say the same thing as the colour.
- A dismiss button is icon-only, so it needs an `aria-label`. Move focus somewhere sensible after it removes the alert.
