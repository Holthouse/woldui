`type="single"` allows one pressed item, like a segmented control. `variant` and `size` set on the group apply to every item.

`spacing` sets the gap between items in spacing units (2 by default). `spacing={0}` joins them into one control with shared borders.

## Accessibility

- The group is one tab stop. The arrow keys move between items, and Space or Enter presses the focused one.
- With `type="single"` the group is a `radiogroup` of `radio` items with `aria-checked`. With `type="multiple"` it is a `toolbar` of buttons with `aria-pressed`.
- Name the group with `aria-label`, and give every icon-only item an `aria-label` of its own.
- In a single group, pressing the pressed item again clears the value. If one must always be chosen, control `value` and ignore the empty string in `onValueChange`.
- `orientation="vertical"` stacks the items. It is a layout prop only: both Left/Right and Up/Down move focus whichever way the group is laid out.
