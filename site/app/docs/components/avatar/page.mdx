## Sizes

`size` is `sm`, `default` or `lg`. `AvatarBadge` pins a status dot to the corner and scales with the avatar; it is `bg-primary` unless you pass a colour.

<Example name="avatar/sizes">
	<Sizes />
</Example>

## Group

`AvatarGroup` overlaps its avatars and rings each one in the background colour. `AvatarGroupCount` closes the row with the number left over, and matches the avatars' size.

<Example name="avatar/group">
	<Group />
</Example>

## Accessibility

- `AvatarImage` needs `alt` text: the person's name, or `alt=""` when the name is already printed beside it.
- Initials alone are a poor name for a screen reader. Put the full name next to the avatar, or give the group `role="group"` and an `aria-label`.
- `AvatarBadge` is only a coloured dot. Put the status inside it as `sr-only` text, or print it beside the avatar.
