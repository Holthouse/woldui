## Usage

<Example name="scroll-area/usage">

</Example>

Give the `ScrollArea` a fixed height (or width) and it scrolls whatever overflows. A vertical scrollbar is built in and appears on hover when the content overflows.

## Horizontal

Add a `<ScrollBar orientation="horizontal" />` for sideways scrolling, and let the content grow wider than the area with `w-max`.

</Example>

## Accessibility

- Native scrolling still does the work, so the mouse wheel, touch and trackpad behave as usual, and the page's own keyboard scrolling works once focus is inside.
- The viewport is not in the tab order. If the content has no links or buttons, a keyboard user may not be able to scroll it; keep something focusable inside, as both examples do.
- The custom scrollbar is for pointers only: it has no role and takes no keyboard focus.
