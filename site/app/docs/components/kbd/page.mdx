`KbdGroup` sets a group of keys that are pressed together, such as a shortcut.

## Accessibility

- It renders a `<kbd>` element, which screen readers announce as keyboard input.
- Write key names out (`Ctrl`, not `⌃`) where a symbol could be ambiguous.
