Its parts match [Dropdown Menu](/docs/components/dropdown-menu): items with a `destructive` variant, checkbox and radio items, labels, separators, shortcuts and submenus. `inset` lines an item up with the text of checkbox and radio items.

<Callout tone="warning">
	A context menu is hidden until someone thinks to right-click. Make every action in it available
	another way too, such as a visible menu button.
</Callout>

## Accessibility

- It opens on right-click and on long-press on touch screens. Shift+F10 and the Menu key send the same event, but only to an element with focus, so a plain `<div>` trigger is out of keyboard reach. That is another reason to offer the actions elsewhere.
- Arrow keys move through the items, typing a letter jumps to the item that starts with it, Right opens a submenu and Left closes it.
- Escape closes the menu. Checkbox and radio items announce whether they are checked.
