## Variants

`variant` sets the shape. `flat` and `faded` are tinted with the tone's own scale, which is where most of the HeroUI character lives.

## Tones

`tone` sets the colour, independently of the shape, so every variant comes in every tone.

<Example name="button/tones">

</Example>

<Callout>
	HeroUI calls this prop `color`. WoldUI calls it `tone`, because `<button>` already has a native `color` attribute, and a variant with that name breaks any component that spreads button props onto an element.

## Accessibility

- It renders a native `<button>`, so Enter and Space activate it and it joins the tab order.
- The focus ring is a 2px outline offset from the button, visible on keyboard focus only.
- An icon-only button needs an `aria-label` — the icon itself is decorative.
- Under `prefers-reduced-motion`, neither the press scale nor the ripple runs.
- `ghost` keeps shadcn's meaning (no border, tonal hover) because many composed components use it. HeroUI's outlined look is `bordered`.
