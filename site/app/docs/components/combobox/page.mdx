## Usage

<Example name="combobox/usage" align="start" tall>
	<Usage />
</Example>

Pass the options to `Combobox` as `items` and it filters them against the input. `ComboboxEmpty` shows when nothing matches. `ComboboxInput` draws the chevron trigger; `showClear` adds a clear button.

## Multiple

With `multiple`, the choices become chips. `ComboboxChips` replaces the input, and `useComboboxAnchor` hands its element to `ComboboxContent` so the list lines up under the whole field. When `ComboboxList` gets a function as its child, it renders the filtered `items` for you.

<Example name="combobox/multiple" align="start" tall>
	<Multiple />
</Example>

## Accessibility

- The input has `role="combobox"` with `aria-expanded` and `aria-controls` pointing at the listbox, and the highlighted option is tracked with `aria-activedescendant`.
- Arrow Up and Down move through the options, Enter selects, and Escape closes the list.
- The input needs a name: an `aria-label`, as above, or a visible `<label>`.
- Each chip has its own remove button, so a choice can be dropped without editing the text.
