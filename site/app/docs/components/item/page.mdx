## Usage

`ItemContent` takes the free space, so `ItemActions` lines up at the end of every row. `ItemMedia variant="icon"` sizes an icon to 16px, and `variant="image"` crops an image to a small square. `ItemHeader` and `ItemFooter` span the full width above or below the row.

## Variants and sizes

`variant` sets the surface: none, a border, or a muted fill. `size` tightens the padding for denser lists.

## Accessibility

- `ItemGroup` has `role="list"`, but `Item` has no role of its own. Give each item inside a group `role="listitem"`, so the list is valid and its count is announced.
- `ItemSeparator` is decorative and hidden from assistive tech.
- A linked item's accessible name is all of its text, title and description together. Keep the description short.
- Don't put buttons inside a linked item: interactive elements can't nest. Use a plain item with a link in the title and buttons in `ItemActions` instead.
