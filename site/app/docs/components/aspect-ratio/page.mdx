## Usage

<Example name="aspect-ratio/usage">
	<Usage />
</Example>

It takes the width of its parent, so size the wrapper rather than the ratio box. Put an `<img>` or `<video>` inside with `className="size-full object-cover"` to fill it.

## Ratios

`ratio` is a number: width divided by height. Write it as a fraction (`4 / 3`) so the intent reads at a glance.

<Example name="aspect-ratio/ratios">
	<Ratios />
</Example>

## Accessibility

- It renders plain `<div>`s and adds no semantics of its own.
- An image inside still needs its own `alt` text, or `alt=""` when it is decorative.
