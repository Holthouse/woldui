## Usage

<Example name="hover-card/usage">
	<Usage />
</Example>

`openDelay` and `closeDelay` on `HoverCard` set how long the pointer must rest before it opens and how long it lingers after the pointer leaves.

<Callout tone="warning">
	A hover card is for sighted pointer users only. Never put anything in it that is not also
	reachable another way, such as on the page the link leads to.
</Callout>

## Accessibility

- It also opens when the trigger receives keyboard focus, but its content is not in the tab order and screen readers do not announce it.
- Touch screens have no hover, so it does not open there at all.
- The trigger should be a real link or button that does something useful on its own.
