## Sizes

`size="sm"` tightens the padding and gaps, for dense grids of cards such as stats. Both come from one `--card-spacing` variable, so every part moves together.

## Dividers

Add `border-b` to `CardHeader` or `border-t` to `CardFooter` and the card adds matching padding on that side, so the rule sits evenly between sections.

## Accessibility

- Every part renders a plain `<div>`, so a card adds no semantics. `CardTitle` is not a heading: put an `<h2>` to `<h4>` inside it when the card should appear in the page outline, at the level that fits the page.
- For a list of cards, wrap them in a `<ul>` with each card in an `<li>`, so the count is announced.
- To make a whole card clickable, keep one real link or button inside (usually on the title) and stretch its hit area with a pseudo-element. Don't wrap the card in an `<a>`: any button inside it becomes invalid.
- A form inside a card still needs its own labels. The [Field](/docs/atoms/field) atom wires the label, description and errors for you.
- Avoid `muted-foreground` text on a `muted` fill inside a card: that pairing falls below AA contrast.
